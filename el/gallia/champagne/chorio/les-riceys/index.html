    Οινοποιεία: Les Riceys

    Το Les Riceys έχει 3 οινοπαραγωγούς στον οδηγό μας, στη ζώνη Côte des Bar. Οι ποικιλίες που συναντάτε συχνότερα στα βαθμολογημένα κρασιά του είναι Pinot Noir. Σε απόσταση που φτάνετε με τα πόδια υπάρχουν 0 μέρη για φαγητό και ποτό και 3 καταλύματα.

    Δέχεται επισκέπτες Άλλοι παραγωγοί Η θέση είναι το κέντρο του χωριού Εστιατόριο ή ταβέρνα κρασιού Κατάλυμα
